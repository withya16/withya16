## 👩🏻‍💻 About Me

Data engineer working across the full lifecycle of data — from batch and streaming pipelines to the governance, quality, and semantic structure (ontology, lineage) that make it trustworthy and usable downstream.

At a pharmaceutical company, that spans production-grade pipeline design, organizational-scale governance frameworks, and increasingly, how data is modeled and connected — ontology, knowledge graphs — so it means the same thing to every system that touches it.

Also exploring where this foundation meets AI: agent systems and AX initiatives built on data that's actually structured to support them.

- Batch & streaming pipelines · production-grade
- Data governance, quality & semantic modeling (ontology, lineage)
